# GreenTech Solutions Website

## Project Description
This website was created for GreenTech Solutions, a company focused on environmental sustainability and eco-friendly technology. The site provides information about the company, products, sustainability resources, and contact information for potential customers.

## Live Site
https://awilli98.github.io/FinalProject/

## Features
- Semantic HTML5 structure
- External CSS styling
- JavaScript product search feature
- JavaScript contact form validation
- Mobile responsive design
- Accessibility features including alt text and form labels
- Navigation across all pages

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## How to Run
Open the index.html file in a web browser or visit the GitHub Pages live site link.
